# Описание проекта "Telegram-бот для студентов"

## Название проекта
StudyBot — интеллектуальный помощник для выполнения лабораторных работ.

## Цель и задачи
**Цель:** Сократить время студентов на поиск информации по лабораторным работам.

**Задачи:**
1. Разработать Telegram-бота с интерактивным меню.
2. Реализовать базу данных SQLite.
3. Добавить напоминания.
4. Создать викторину.
5. Обработка фото (модификация).

## Технологии
Python, python-telegram-bot, SQLite, Git, HTML/CSS.
