# Описание проекта "Telegram-бот для студентов"

## Название проекта
StudyBot — помощник для выполнения лабораторных работ.

## Цель и задачи
**Цель:** Сократить время студентов на поиск информации по лабораторным работам.

**Задачи:**
1. Разработать Telegram-бота с меню и кнопками.
2. Реализовать базу данных SQLite для хранения вопросов.
3. Добавить механизм напоминаний о дедлайнах.
4. Создать викторину для проверки знаний.
5. Сделать модификацию — бот отвечает на фото.

## Технологический стек
- Python 3.10
- Библиотека python-telegram-bot
- SQLite3
- Git / GitHub
- HTML, CSS
